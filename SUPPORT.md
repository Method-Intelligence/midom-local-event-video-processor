# Support

## For Event Staff

If you were asked to run this app for a Midom Video Collection Event, contact the person or organization that gave you the pairing code.

Helpful information to send them:

- What computer you are using: Windows or Linux.
- What you were trying to do.
- The last few lines shown in the processor window.
- Whether the processor had worked before on this computer.

Do not send pairing codes or worker tokens in screenshots or support messages.

## For Project Administrators

First checks:

- Confirm the Video Collection Event is configured to use paired project workers.
- Confirm the processor is paired to the correct Midom project.
- Confirm the processor window is still open.
- Confirm Midom shows the worker as ready or recently active.
- Confirm the event has compatible processing settings and required overlay/bumper assets.

If a worker is stale, revoked, expired, or unhealthy, disconnect/revoke it in Midom and create a fresh pairing code.

## For Developers

Use GitHub issues for ordinary bugs, packaging issues, documentation problems, and feature requests.

For security issues, do not open a public issue. See `SECURITY.md`.
